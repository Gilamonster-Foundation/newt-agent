# newt-skills

Newt-Agent [agentskills.io](https://agentskills.io)-compatible skills —
discovery + `SKILL.md` parsing for progressive disclosure.

A skill is procedural knowledge the agent loads on demand. Skills are plain
folders on disk (a `SKILL.md` with YAML frontmatter + Markdown body, plus
optional bundled files), so they stay portable across the whole Gilamonster
agent line (newt-agent, hermes-thoon) and Anthropic's Claude Code — anything
that speaks the agentskills.io format.

Part of [Newt-Agent](https://github.com/Gilamonster-Foundation/newt-agent), a
free, friendly, local agentic coder.
