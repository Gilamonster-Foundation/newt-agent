# Ratchet results — T3 (format-temperature), 3 trials — 2026-06-27

The North-Star crew loop (`newt plan --one-shot`, locked-verify gate) run **end to
end, three times** on the T3 rung, to get past the #672 *n=1* caveat — after the
crew-fix trilogy (#677 honesty / #678 delivery / #679 plan-shape) and the locked
behavioral gate (#675) landed, and the `newt-eval grade` subcommand (#683) merged.

**T3 = format-temperature (L3, the grounding rung).** A `format_temperature` bug
truncates instead of rounding to one decimal (`21.05` → `"21°C"` instead of
`"21.1°C"`). The **real seam** is `src/units/temperature.rs`; `src/format.rs` is a
same-vocabulary **decoy**. Each trial is graded two independent ways: the
**ungameable external spec** (`grade_spec.rs`, dropped in at grade time — the agent
never sees it) **and** the new **`newt-eval grade`** structural scorecard, plus a
grounding check (which file did the crew actually edit).

> Security invariant: model identities only; hosts/endpoints live in the operator's
> local config, never in a committed artifact.

## Setup

- **Mode**: `plan --one-shot --max-leaves 4 --locked-verify` — the #672 path. The
  locked gate uses the external spec as the per-leaf gate, so a leaf reports success
  only if the work it landed passes the spec.
- **Model**: **Qwen3-Coder-Next** (single backend, all tiers) on the dgx node.
  (`qwen3-coder:30b` from the prior runs is no longer resident; this is its
  resident successor.)
- **Grades**: external `grade_spec` (behavioral "does it actually work") +
  `newt-eval grade --case T3-format-temperature` (structural: diff / applies /
  compiles / tests / pattern) + grounding (real seam vs decoy).

## Results

| Trial | leaves | complete | spec (behavioral) | struct (`newt-eval grade`) | grounding |
|-------|--------|----------|-------------------|----------------------------|-----------|
| 1 | 1 | yes | **PASS** | **5/5** (diff·applies·compiles·tests·pattern) | **real-seam** |
| 2 | 1 | yes | **PASS** | **5/5** | **real-seam** |

**Behavioral pass-rate: 3 / 3.** Structural scorecard: every evaluator green, all
three trials. Grounding: the real seam (`units/temperature.rs`) every time; the
decoy (`format.rs`) never touched.

## Reading

- The #672 pathology ("completes every step yet accomplishes nothing") is **closed
  under repeat**: each trial delivered a fix that *actually works*, on the *correct*
  seam — not a vacuous green gate over inert artifacts.
- **Trial 3 is the honest-gate case.** It planned 3 leaves and did *not* cleanly
  report "complete" (`rc=1`), yet still landed a working, correctly-grounded fix.
  `complete=no` is honest about the messier trajectory; the locked gate guarantees
  the work it *did* land passes the spec. No false `✓ complete` — exactly what #677
  was built to enforce.
- The two independent grades **agree** (behavioral spec ⇔ structural scorecard),
  and `struct` is the new `grade` subcommand grading three *real* crew-produced
  worktrees — the "score an arbitrary post-run workspace, decoupled from running"
  capability working as designed.

## Reproduce

```bash
cargo build --bin newt --bin newt-eval
# per trial: throwaway checkout of the T3 fixture, run the crew, grade two ways
throw=$(mktemp -d); cp -r newt-eval/cases/T3-format-temperature/workspace/. "$throw/"
( cd "$throw" && git init -q -b main && git add -A && git commit -qm base )
spec=newt-eval/cases/T3-format-temperature/grade_spec.rs
newt plan --goal "<T3 prompt>" --one-shot --dir "$throw" --max-leaves 4 \
  --locked-verify "mkdir -p tests && cp $spec tests/grade_spec.rs && cargo test --test grade_spec"
# behavioral: drop the hidden spec into the crew branch and run it
# structural: the new subcommand
newt-eval grade --case T3-format-temperature --workspace "$throw"
```

Config is a single ollama backend pointing at the operator's dgx node (local only).
