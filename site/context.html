How Newt manages context

A model's window is small and every turn re-sends it. When the window nears its budget, Newt does not throw the middle away. It keeps the task, keeps the recent work, saves the rest verbatim, and leaves the model a way to ask for it back. Step through one compaction below.

Going further

How agent-frame relates: this page is the default compaction path, which does not use it. The opt-in smart harness does, to record the session and validate which context to keep.

Paged context is the design that would extend this: bounded residency with unbounded reach, served from a derivation graph. It is not built yet, and the page says which parts are.

What each stage maps to

StageWhat it doesWhere
Structural pruneZero-LLM-cost passes shrink stale tool output first. Most triggers end here.compress.rs
BoundaryHead is every leading system message plus the active-prompt card, so the task can never be summarized away. The tail is protected by a token budget, with the latest user message anchored in it. The cut never splits a tool call from its result.compress.rs
SpillThe verbatim middle is redacted and stored under a content-addressed handle (a BLAKE3 CID). Same bytes, same handle.spill identity decision
SummarizeA summarizer writes a reference-only card, fenced by start and end markers so weak local models do not read it as a fresh request. No summarizer, or a failed one, falls back to a plain "N messages were removed" marker and the turn goes on.compress.rs
Page faultThe model calls memory_fetch with the handle and gets the verbatim span back, only when it needs the detail.newt-core/src/agentic/memory_fetch.rs
Anti-thrashTwo compactions in a row that each reclaim under 10% turn auto-compaction off for the session and tell the operator once. The budget guard stays hard: an over-budget send is refused, never silently truncated.CompressState in compress.rs

Built, and not yet built

The design behind this is progressive disclosure: the window is a budgeted resource and the model pulls what it needs. The model is never told it holds everything. It is told what it holds and that the rest is reachable, because a confident summary suppresses re-reading while a labelled absence prompts it (measured here).

The wider idea, paged context over a derivation graph, is recorded intent and has no implementation yet. The animation above does not depict it; the linked page animates the design and labels it as such.
