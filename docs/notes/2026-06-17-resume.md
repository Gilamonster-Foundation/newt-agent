## The `newt-scheduler` crate (the data plane) — state + next

A **default-workspace** crate, pure core + injected I/O behind traits, ~99% self-cov.
Trait decomposition (the user's explicit design directive — "a nice set of traits to
drive decomposition"):

- **`PoolSource`** (population) — `StaticSource` from config now; a feature-gated
  `MeshSource` (mDNS presence → live membership) later.
- **`Prober`** (health) — `TcpProber` reachability now; an HTTP `/api/tags` prober
  (also refreshing the *model inventory*) is a small refinement.
- **`Dispatcher`** (inference strategy, **#418**) — `LocalDispatcher` reuses
  newt-inference; a `MeshDispatcher` (remote) swaps in behind the `mesh` feature.
- `BackendPool` — model-pin routing, `Busy≠Down`, count-adaptive dispatch
  (0→Refuse/1→TimeSlice/N→FanOut), `ranked_candidates`, `run_role` (select + dispatch
  + failover).

**NEXT slices (in order):**
1. **The role-routing control loop** — add a **`Workspace` trait** (apply edit / run
   test / diff) and orchestrate navigate→curate→plan→apply→verify→triage over

3. **HTTP `/api/tags` prober** (refresh reachability *and* model inventory).

## Authority plane — OCAP (gated, do not rush)

- **Threat-model verdict: `unsound-needs-rework`** ([`design/captured-shell-ocap.md`](../design/captured-shell-ocap.md) §4,
  panel `wf_ebb2efe5-b41`). The authority **algebra** (meet-only signed AgentKey
  delegation + deny-default) is sound; **enforcement is unbuilt**: B1 (OS isolation +
  egress proxy) is zero-code, the disclosure gate isn't on the live tool-result path,
  redaction is shape-only.
- **Binding reframe:** redaction is NOT the boundary — the **egress proxy + keeping the
  token OUT of the box** is. Don't let the model see the credential.
- **The deviation ratchet** ([`security/ocap-deviations.md`](../security/ocap-deviations.md)):
  effective authority = `meet(human grant, what verified invariants enforce)`; a
  deviation fail-closes its dependent capabilities; `just ocap-check` (held on
  `feat/ocap-check`) is the honesty gate.
- **New on main:** [`design/captured-shell-cross-platform.md`](../design/captured-shell-cross-platform.md)
  makes B1 **per-OS** (Linux Landlock+seccomp+netns / macOS Seatbelt / Windows
  AppContainer) and grounds the brush-as-portable-interpreter-gate vision. (brush is
  **not wired** yet — agent-bridle `stub-shell`.)
- **3 MUSTs gate any live credential:** fail-closed runtime-verified B1; close the
  in-process monitor holes (live-path taint redaction, `openat2` fs fence,
  behavior-bound exec, MCP under the leash); a real proposer≠worker human spine.
- **Do NOT seed a live `pa` credential into the box until B1 is fail-closed.** The crew
  MVP is unblocked because coding tasks need no credential.

## Load-bearing decisions / constraints

- **Naming:** "crew loadout" (role-specialized ensemble); "progressive-disclosure" over
  "paging"; the diverse "panel" is the same machinery as the crew, opposite intent.
- **Scheduler lives in `newt-scheduler`** (default build), NOT `newt-mesh` (path-deps
  agent-mesh; cargo validates eagerly even behind a feature). Mesh dispatch is the
  `mesh`-feature swap.
- **MSRV 1.75** — no `is_none_or`/`is_some_and`-era APIs without checking; clippy's
  `incompatible-msrv` is `-D warnings`.
- **Honest gates:** every PR clears `just check` + `just cov-ci` (floor ratchets up,
  never down; currently ~89%). Never seed a live credential past an open OCAP deviation.
- **Stacked-PR hazard learned twice:** don't `--delete-branch` a base that has open
  stacked PRs (it auto-closes them); and a squash-merge strands later commits pushed to
  the same branch (re-land via cherry-pick onto current main — that's how #418 happened).
