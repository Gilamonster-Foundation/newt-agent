## What it's good for
Context-management taxonomy lives in **§3.2 "Memory and Context Engineering"**
(pp.21–24, Fig.6, Table 5), classifying memory by functional role: working,
semantic (repo-evidence retrieval), experiential (write-gated cross-task),
long-term (governance), multi-agent, and compaction/offloading. **§4.3**
(pp.43–48) covers shared-substrate representations (file-only, repo/AST-skeleton,
execution-based, blackboard) — notable line (p.48): *"context management is the
tax of implicit shared state."*
