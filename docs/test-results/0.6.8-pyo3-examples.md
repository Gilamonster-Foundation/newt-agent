# 0.6.8 baseline — PyO3 examples under context overflow

**Version:** 0.6.8 · **Date:** 2026-06-14 · **Experiment:** the "one Python
example per PyO3 crate" task on an **8-crate (~20k-token) overflow corpus** —
see [methodology](../methodology/). **Outcomes:** ✅ pass · ❌ fabricated · ◐
vacuous (wrote `.py`, no imports) · ∅ no-output · ⚠ timeout/error.

## Headline — the dominant barrier is the tool-call protocol, not fabrication

The result we expected (nemotron fabricates the API surface) is confirmed, but
the **bigger** finding is upstream of it: **most local models never complete the
task because of how they do — or don't — tool-call in newt's agentic loop**, not
because they fabricate. On the gnuc 4060 Ti, only 5 of 19 models even produced
imports to judge. The "no-output" majority decomposes into distinct,
**mostly-fixable harness gaps** (see the breakdown below). This reframes 0.6.9:
the first lever is the tool-call layer, *then* nemotron-family fabrication.

## Reading the result

- **Engaging models split cleanly by family.** Of the models that produced
  imports: `gemma4` (e2b, e4b) and `qwen3-coder:30b` **pass**; the **nemotron**
  family **fabricates** (`nemotron-3-nano:latest`) or writes import-less stubs
  (`nemotron-3-nano:4b`). Consistent with the cross-family finding
  ([findings/2026-06-14](../findings/2026-06-14-cross-family-confabulation.md)).
- **The tool-call layer gates everything.** 10 of 13 no-output cells are tool-call
  issues — 6 no-tool-support, 4 a JSON-in-content dialect newt silently drops.
  These models never reach the fabrication question.
- `gemma4:e4b` is the one engaging model that hit the **round cap** (25 events) —
  a candidate for the decomposition help nemotron also needs.

## 0.6.9 targets (reframed by this baseline)

1. **Parse JSON-in-content tool calls** — unlock qwen2.5-coder + llama3.1 (the
   largest blocked group, and they're *trying*).
2. **Non-tool whole-file fallback** for models with no Ollama tool support.
3. **Fix the session-plan-file UX trap** (mistral-small loop).
4. **Nemotron-family fabrication** — the original target: decomposition / curated
   context / verify gate so the working set fits and fabrications are caught.

We may not get every model passing; the line is the **nemotron family green**,
with the tool-call fixes as the prerequisite that lets most others even start.

## Caveats

One run per cell; module-level scoring (#74 adds symbol-level); forensics
unrecorded for a few fast runs (score still valid); timeouts/OOM are hardware-
bound (a model blocked on the 4060 Ti may differ on the DGX Spark).
