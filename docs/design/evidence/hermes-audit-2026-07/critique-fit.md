## 2. INERTNESS — strongest case per ADOPT item

(a) Per the ledger, the frozen-prefix contract and frozen-snapshot memory already exist; the remaining sub-items are imports of *Python-shaped* bugs — tool-call JSON canonicalization fixes Python dict-order nondeterminism that Rust serde struct serialization doesn't have by construction. (b) The doc never reconciles A1 with newt's own compression design: the prune→summarize→marker pipeline **rewrites history by design**, and mid-loop trim mutates messages — every compaction busts the entire KV prefix regardless of byte discipline. On exactly the long flights where cache reuse would pay most, the compressor invalidates it periodically anyway. A1 isn't *incoherent* with compression (between-compaction reuse is real), but "single highest-value import" is asserted with zero measurement: newt's eval harness has no KV-cache-hit or latency metric, so this flagship item is un-evaluable under the doc's own "measured lift" discipline as things stand. (c) Eval runs are `--ephemeral` and cold; the resume-byte-identical machinery pays only when the operator resumes inside a cache-warm serving process.

**A2.** The doc asserts "kills premature 'done' claims" without one cite of newt-side incidence. The audit's *own* live observation this week was round-budget pressure (cited under A3) — a failure mode A2 makes *worse*: a model out of rounds gets refused at stop and nudged (≤2 more rounds) to run verification it has no budget for. There's also tension with the doc's own headline: hermes removed budget-pressure nudges because models "give up prematurely" — a stop-time refusal quoting failing output is a pressure signal of a sibling class, untested on newt's weak-local-model audience. And the "workspace edited" trigger has a false-positive class (docs/config/scratch edits with no runtime surface) that LanguagePack verify commands can't classify. A2 is the *right law* (harness owns verification), but the premise — that newt's solo loop measurably suffers premature-done — is unestablished. Build the measurement first; the mechanism is only adoptable if the metric moves.

**A3.** Inertness aside (see §5 for security): the claimed payoff overlaps almost entirely with things already landing — #942/#945 output caps, A8 aggregate budgets, spill + `memory_fetch` paging (spill.rs, verified live), and #948. ## 5. A3 SECURITY — the strongest case against, under newt's OCAP model

"The dispatcher takes the met-down caveat set as an explicit value" secures exactly **one of two legs**: the RPC leg. It does nothing for the execution leg, and the execution leg is the attack surface.

1. **A script is a Turing-complete argv bypass.** Newt's caveat lattice (the #34 argv-engine) reasons about tool invocations — command shape, paths, argv. A model-authored script's *body* is opaque to that engine: inside the child process, raw `open()`, `socket()`, `exec()` are syscalls, not tool calls, and no caveat ever sees them. "A confined child process" is load-bearing and undefined — hermes's confinement is a Unix socket and a prayer (their trust model is what AVOID-4 exists to mock). Without OS-level confinement (namespaces/seccomp/landlock, no-net, fs scoped to the worktree), A3 reintroduces precisely the ambient authority the lattice was built to kill. "Only stdout returns to context" is an output *discipline*, not an authority *boundary*.

2. **Caveat-set snapshot = TOCTOU.** Taking the met-down set "as an explicit value" at script start means mid-flight attenuation (a human tightening authority, a grace-round downgrade) doesn't reach a running script. Hermes's #33057/#30882 bug class — approval context vanishing across an execution boundary — is cited as the thing newt's lattice structurally fixes, but a snapshotted value crossing a process boundary is the *same shape of bug* with better marketing: the authority context and the execution context have been decoupled again.

3. **Approval semantics don't compose at machine speed.** Interactive caveats ("prompt the human for writes outside the workspace") now fire over an RPC socket from inside a running script — block-and-deadlock, timeout, or auto-deny; each is a new failure mode the lattice was never specced for. And the amphibious rule makes this binding: **wyvern has no human and no hatch** — every script-triggered caveat must be lattice-decidable without a prompt, or the script tool can't exist in the flight tier that newt exists to be the testing ground for.

4. **Aggregation defeats per-call caveats.** Every individual `read_file` passes its caveat; a script composes ten thousand of them in one round, funnels the result through the one channel no caveat governs — stdout into model context — from which any net-capable tool exfiltrates it. Rate, volume, and human-observability assumptions under which per-call caveats were written are all voided by machine-speed composition. This is the confused-deputy scenario (the operator's own doctrine): the dispatcher is a deputy executing on behalf of code authored inside a possibly prompt-injected context, with session authority.

**Verdict on the stated mitigation: insufficient.** Script execution needs its **own caveat class** — interpreter admission, wall/CPU limits, syscall confinement profile, no-net-in-child default, aggregate stdout byte budget, tool-call count budget, snapshot-invalidation-on-attenuation — plus a Lean-specced meet with the session lattice, *before* the tool exists. That is OCAP design work of the same order as the enforcement-floor stack, which is exactly why A3's wave-3 slot is wrong.
