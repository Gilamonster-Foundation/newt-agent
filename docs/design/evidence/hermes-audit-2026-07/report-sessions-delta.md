# hermes-agent SESSION/STATE layer — delta since 2026-06-10

**Scale note first:** the layer grew fast in <4 weeks. `gateway/run.py` is now 20,526 lines / ~995KB, `cli.py` ~743KB (was ~630KB at study time), `hermes_state.py` 6,322 lines, `run_agent.py` ~269KB. ~75 commits touched just the four surveyed files since 2026-06-10. The single-file monolith pattern is worsening, and a visible fraction of the delta is regression-chasing fallout from earlier deltas (e.g. `tests/test_lazy_session_regressions.py`-class bugs, #46994 corrupted-entry aborts, #49148 delegate-cascade cycle eating parents).

## Genuinely NEW since the study

1. **Non-destructive in-place compaction (#38763).** New `messages.active` and `messages.compacted` columns (`hermes_state.py:766-767`) + `archive_and_compact()` (`hermes_state.py:3651-3701`): one transaction flips live rows to `active=0, compacted=1` and inserts the compacted set as fresh active rows. **One session id for life**; live context load filters `active=1`; archived turns *stay in the FTS index and stay searchable* by `session_search` (compacted=1 rows included by default, `hermes_state.py:4521-4527`), and are recoverable via `include_inactive=True`. Config-gated (`compression.in_place`, default off — `agent/conversation_compression.py:485-491`), so the old rotate-session/`parent_session_id` lineage remains the default; the tri-state semantics distinguish "summarized away" (active=0,compacted=1) from **rewind/undo** "user took it back" (active=0,compacted=0, new `/rewind` at `hermes_state.py:4171-4174`, `sessions.rewind_count` column).
2. **New session columns:** `chat_id/chat_type/thread_id/display_name/origin_json` (persisted origin proof), `cwd/git_branch/git_repo_root` (git workspace metadata, commit 4cdd1a323), `billing_provider/base_url/mode` + five cost columns (mid-session `/model` switch billing correctness, c7e934a5b), `compression_failure_cooldown_until/error` (**compression backoff now survives restarts** — the study noted in-memory 600s/60s/30s cooldowns; #54465 persisted them), `rewind_count`, `archived` (`hermes_state.py:696-757`).
3. **`compression_locks` table** (`hermes_state.py:783-788`, `try_acquire_compression_lock` 2223-2283): cross-process lease with expiry so two writers (gateway + ACP adapter sharing a session) can't compact the same session concurrently.
4. **FTS self-maintenance:** (a) a three-rung **corruption repair ladder** — in-place FTS5 `'rebuild'` → dedupe `sqlite_master` → drop-FTS+VACUUM+rebuild-from-canonical-rows, with timestamped backup first and canonical tables never modified (`hermes_state.py:560-690`, #52798); (b) **periodic `'optimize'` segment merges** to curb write-lock contention (`hermes_state.py:1225-1237, 6057-6092`, commit 0695a6bce); (c) graceful missing-trigram-tokenizer fallback rather than disabling FTS wholesale (0403f41f9).
5. **Resume-security hardening (V-009 + PR #52355 reviews):** `SessionEntry.from_dict` rejects path traversal and Windows drive-letter session fields (commits c8eb7cf84/3a6a43cb8/aa2aac68b); persisted `/resume` must **prove chat/thread origin** — a same-user-different-chat caller can no longer resume another chat's row (5248877c6, hence `origin_json`).
6. **Prompt-injection neutralization of session metadata:** attacker-controllable chat/room display names are format-neutralized before entering the system prompt (`_format_untrusted_prompt_value`, commits 09666ceb7 + dbad6d47d).
7. **Compression-tip resolution hardened:** `resolve_resume_session_id` now walks to the lineage tip FIRST via `get_compression_tip` — lineage-aware, only follows `end_reason='compression'` children so delegate/branch/tool children never hijack a resume; depth cap 32 (`hermes_state.py:3936-3976`, commits abd6b8520/6dfb8326f). Fixes "I came back and the reply isn't there."
8. **Delegate-cascade delete:** `_delegate_from` marker in `model_config` JSON drives recursive cascade-delete of subagent children, with a visited-set cycle guard after #49148 (a parent collected as its own descendant got deleted with all messages) — `hermes_state.py:80-125`. Untagged children keep the orphan-don't-delete contract.
9. **`AsyncSessionDB`** — a `__getattr__`-forwarding facade wrapping every DB call in `asyncio.to_thread` (`hermes_state.py:6308-6322`).
10. **Ordering fix:** conversation replay now orders by `id`, not timestamp (f049227f3) — same-second rows interleaved wrongly.
11. **Session_context subprocess-env leak fix:** a process-level `_session_context_engaged` monotonic latch; once any session binds ContextVars, the subprocess-env bridge stops inheriting the last-writer-wins `os.environ` mirror into child processes, closing a cross-session identity leak into shelled-out tools (`gateway/session_context.py:44-66, 252-267`, commit cc395e805).

`trajectory_compressor.py` is RL-training-data post-processing (protect head/tail, summarize middle of completed trajectories to a token budget — `trajectory_compressor.py:1-30`); its delta is two hygiene commits — not session-layer relevant.

## Candidate learnings for newt

1. **Soft-archive compaction (active/compacted tri-state) instead of destructive prune.** Mechanism: when newt's structural-prune/LLM-compression pipeline drops turns, don't discard them — flag rows `archived+compacted` in the conversation store so the FTS5/bm25 recall index still covers them, while the live-context load filters to active rows (`hermes_state.py:3651-3701`). Plugs into: newt's SQLite FTS5 conversation-recall store + the compression pipeline in `newt-core/src/agentic/`. Payoff: closes the "compression amnesia" hole — today a compacted-away detail is unrecallable by newt's own settled recall mechanism; hermes hit exactly this (#38763, 854d75723 "keep compaction-archived turns discoverable"). This complements — does not reopen — the settled no-embeddings decision; it's the same bm25 index over more rows. The rewind semantics (active=0,compacted=0 = "user took it back", excluded from recall) is a worthwhile distinction if newt ever adds undo.
2. **Freshness-gated resume_pending.** Mechanism: stamp `last_resume_marked_at`; at resume time, gate on a configurable window (default 1h), expiring to a normal fresh-start with an explicit reason string (`gateway/session.py:30-57, 1707-1727`). Plugs into: newt's session resume / crew-worker restart handling (a worker killed mid-flight in a worktree). Payoff: prevents zombie auto-continuation of stale interrupted turns — a bug class hermes only found after shipping unconditional auto-resume. Cheap: one timestamp + one comparison, and `0` disables it (configuration, per the three Cs).
3. **FTS index self-maintenance: periodic `'optimize'` + escalating repair ladder.** Mechanism: `INSERT INTO fts(fts) VALUES('optimize')` on a counter to merge b-tree segments (`hermes_state.py:6057-6092`); on corruption, try `'rebuild'` from canonical rows before anything destructive, backup first, never touch canonical tables (`hermes_state.py:560-690`). Plugs into: newt's FTS5 recall store maintenance path. Payoff: hermes measured real write-lock contention and silent history-dropping (#50502/#52798) from unmerged segments/corrupt FTS; because FTS is derived data, rebuild-from-canonical is always safe — a good invariant for newt to encode now, in ~50 lines.
4. **Persist compression backoff/cooldown state.** Mechanism: `compression_failure_cooldown_until/error` columns (#54465) so restart doesn't retry a known-broken summarizer in a hot loop. Plugs into: newt's LLM-compression failure handling. Payoff: turns an in-memory politeness into a durable one; trivially testable.
5. **Replay-order by rowid, not timestamp** (f049227f3): if newt ever replays transcripts from its store, order by monotonic insert id — same-second timestamps reorder tool-call/result pairs. A one-line convention worth adopting preemptively.
6. **Migration discipline pattern (meta):** routing-index move done as DB-primary + legacy-mirror-behind-a-flag + import-only-missing-keys + startup self-heal prune (`gateway/session.py:997-1104`). If newt ever migrates a state file format, this is the shape that avoided a flag-day.

## Avoid replicating

1. **The regression treadmill of implicit lifecycle flags.** Hermes now has `suspended`/`resume_pending`/`was_auto_reset`/`is_fresh_reset`/`expiry_finalized`/`archived`/`active`/`compacted`/`rewind_count` spread across two stores, and a large share of the 75-commit delta is fixing interactions among them (zombie resumes, delegate cascades deleting parents #49148, stale routing #54878, ghost sessions). Newt should keep session lifecycle a small explicit state machine with typed transitions (Rust enums make this nearly free) — not accreted boolean columns.
2. **Two sources of truth, even temporarily unbounded.** The JSONL+SQLite dual-write and the sessions.json mirror each spawned their own bug families (#860 duplicate writes, prefer-the-longer-source truncation guard, crash-stale routing). Newt has one store; keep it that way. Adopt learning #6's *pattern* only if a migration is ever forced — never run a mirror without a scheduled kill date.
3. **`__getattr__`-based AsyncSessionDB facade** (`hermes_state.py:6308`): dynamic forwarding that erases the type surface, justified by a comment saying "the audit confirms no method returns a live cursor". In Rust this class of "hope the audit holds" is exactly what the type system replaces — no analogue wanted.
4. **Profile/multiplex-stamped session keys + origin-proof machinery** (`gateway/session.py:836-853`, 5248877c6): solves multi-tenant, multi-platform chat routing. Newt is single-operator, local-first, with OCAP caveats already scoping authority; importing key-namespace machinery would be complexity without a threat model. If crew workers ever need session isolation, the caveat lattice — not key stamping — is newt's native answer.
5. **Config-gated dual compaction modes.** Hermes now maintains *both* rotate-session-lineage and in-place-archive compaction, plus a cross-process `compression_locks` table to referee writers. That's a consequence of multiple concurrent frontends (gateway/ACP/TUI/desktop) sharing one DB. Newt has one writer per session by construction; adopt soft-archive (learning #1) as the *only* mode and skip both lineage-graph traversal (recursive CTEs, tip-resolution, depth caps) and the lock table entirely.
6. **Single-file scale.** `gateway/run.py` at ~20.5K lines is where handoff, watchers, resume scheduling, and turn dispatch all live; the study's line-number citations from three weeks ago drifted by thousands of lines. Newt's small-crates discipline is the counter-position — keep it.
