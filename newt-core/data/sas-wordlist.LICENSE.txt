Provenance and license for `sas-wordlist.txt`
=============================================

`sas-wordlist.txt` is the BIP-39 English mnemonic wordlist, vendored verbatim.

  Upstream: https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt
  SHA-256:  2f5eed53a4727b4bf8880d8f3f199efc90e58503646d9ff8eff3a2ed3b24dbda
  Retrieved: 2026-07-25

Vendored rather than fetched so the short authentication string is reproducible
offline and byte-for-byte identical in every port (Rust, browser JS, mobile).
The file is kept pure data — 2048 LF-terminated lowercase ASCII words, no
comments or header — so a port can load it verbatim without a parser. Its
digest is pinned by a law test; see `newt-core/tests/sas_transcript.rs`.

Why this list: 2048 entries give exactly 11 bits per word, so a six-word string
carries 66 bits — above the ceremony's 64-bit floor. Every word is unique in its
first four characters, which bounds transcription error during a two-ended
comparison.
